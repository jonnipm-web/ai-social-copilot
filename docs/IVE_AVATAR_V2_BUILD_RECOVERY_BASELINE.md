## Blocker 2 — flutter analyze global: PostgrestTransformBuilder error

| Field | Value |
|---|---|
| **Command** | `flutter analyze --fatal-warnings` |
| **Exit code** | `1` |
| **First error** | `error • The getter 'eq' isn't defined for the type 'PostgrestTransformBuilder<List<dynamic>>' • lib/data/services/business_memory_service.dart:16:14` |
| **Root cause** | `BusinessMemoryService.fetchAll()` called `.order('created_at', ascending: false)` before calling `.eq()` filters. `.order()` converts a `PostgrestFilterBuilder` to a `PostgrestTransformBuilder`, which does not expose `.eq()`. The workaround `as dynamic` bypassed compile-time checking but the analyzer flagged it. |
| **File** | `lib/data/services/business_memory_service.dart` |
| **Fix** | Restructured query to apply `.eq()` filters first, then `.order()`. Variable typed as `PostgrestFilterBuilder<List<dynamic>>`. No `as dynamic` cast. |

## Blocker 3 — flutter build apk: Android v1 embedding

| Field | Value |
|---|---|
| **Command** | `flutter build apk --debug` |
| **Exit code** | `1` |
| **First error** | `"Build failed due to use of deleted Android v1 embedding"` |
| **Root cause** | The `android/` directory in the repository contained only `android/app/google-services.json`. The full Android project scaffold (build files, Kotlin `MainActivity`, `AndroidManifest.xml`) was missing. CI step 12 incorrectly checked for `android/app/build.gradle` (Groovy DSL, not committed) instead of `android/app/build.gradle.kts` (KTS DSL, generated by Flutter 3.x), causing the step to exit 0 with a skip message rather than failing. |
| **Files created** | `android/app/build.gradle.kts`, `android/app/src/main/kotlin/.../MainActivity.kt`, `android/app/src/main/AndroidManifest.xml`, `android/settings.gradle.kts`, `android/build.gradle.kts`, `android/gradle.properties`, `android/gradle/wrapper/gradle-wrapper.{jar,properties}`, `android/app/src/main/res/**`, `android/local.properties` |
| **Fix** | Ran `flutter create --platforms=android` to scaffold the full v2-embedding Android project, restored `google-services.json`, committed all files. |

## Blocker 4 — CI step 12: wrong build.gradle check (enabling false PASS)

| Field | Value |
|---|---|
| **Command** | CI `.github/workflows/ive-avatar-v2-validation.yml` step `Build APK debug` |
| **Exit code (wrong)** | `0` (silent skip) |
| **Root cause** | The guard `if [ ! -f android/app/build.gradle ]` checked for the Groovy DSL file. Flutter 3.x generates `build.gradle.kts` (Kotlin DSL), which the guard did not match. The step exited 0 with `INFO: APK build skipped`, setting `DEBUG_APK_SHA=N/A` and `DEBUG_APK_SIZE=N/A`. The job summary showed PASS even though no APK was built. |
| **File** | `.github/workflows/ive-avatar-v2-validation.yml` |
| **Fix** | Changed check to `android/app/build.gradle.kts`. Removed the skip-with-exit-0 path entirely — a missing build file is now a CI error (`exit 1`). Removed `N/A`-conditional guards from downstream steps. Added `if-no-files-found: error` to APK upload. Added `apk_hash` to MANDATORY gates array. |
