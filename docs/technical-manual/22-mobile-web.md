# 22 — Mobile / Web

Mobile is a first-class target; both clients build from the same Flutter code.

| Aspect | Android | Web | iOS |
|---|---|---|---|
| Build path (E-MAIN) | `flutter create --platforms android` at CI time + keystore signing (`build-apk.yml`, `build-android.yml`) | `flutter create --platforms web` at CI time + `web/404.html` (versioned) | none |
| Versioned platform scaffold | Only `android/app/google-services.json` on E-MAIN; full `android/app/src` (flavors) on E-INT02 / avatar-lab branches | Only `web/404.html` on E-MAIN; `web/index.html`, icons, manifest on E-INT02 | — |
| Application id | Generated by `flutter create --project-name ai_social_copilot` (so `com.example.*` default unless the scaffold is versioned) → `UNKNOWN` for the released APK; avatar lab uses `com.insightvalues.iveavatarlab` and refuses `com.insightvalues.aisocialcopilot` / `com.example.ai_social_copilot` | n/a | — |
| Distribution | CI artifacts (30-day retention); Play Console: no evidence | GitHub Pages `/ai-social-copilot/` on every push to main | — |
| Routing | GoRouter | GoRouter hash strategy + SPA 404 restore script | — |
| Auth | Google Sign-In via `google-services.json` / strings resource | Google Sign-In web client id | — |
| File import | `file_picker` + Drive | `file_picker` + Drive | — |
| Physical-device evidence | Mission reports (Samsung S25 closures, Physical E2E gates) | Manual browser checks in reports | — |
| Status | `IMPLEMENTED`; release status `UNKNOWN` | `DEPLOYED` per workflow | `NOT_IMPLEMENTED` |

Responsive strategy: width checks (e.g. `ive_overlay.dart` desktop at ≥ 1024 px), two-column
layouts on some screens; audits in `docs/DESKTOP_RESPONSIVE_AUDIT.md` and
`docs/RESPONSIVE_SCREEN_MATRIX.md` (`HISTORICAL_EVIDENCE_ONLY`). `kIsWeb` is used in 4 places.

Offline/online: no offline mode; every feature needs Supabase connectivity. Local state is limited
to `SharedPreferences` (IVE memory, language).

Material web differences: hash URLs; paid-state refresh on tab visibility (Stripe Checkout opens
another tab); `supabase_flutter` pinned `<2.15.0` because of a web passkeys crash on GitHub Pages.
